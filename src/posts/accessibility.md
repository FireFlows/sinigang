### How my website is accessible
As a disabled person myself, I take accessibility very seriously*. So, I made this website with accessibility in mind.

* Works on any resolution and mobile
* Legible text at 200% zoom (and beyond)
* No autoplaying audio, videos, GIFs, etc.
* Semantic HTML whenever possible
* All images (well, I only have one image) have alt text
* Navigable using the [tab] and arrow keys
* Language text set to "en" on all pages
* Minimal distractions
    * no flashing images
    * no popups
* Colors tested for contrast 

In general, I'm a very big advocate of accessibility in web design. I don't like how a lot of personal websites seem to neglect accessibility, mobile compatibility, etc. in favor of "aesthetic" when in reality their website is very ugly. To me, the prettiest websites are accessible!

If there are any accessibility improvements I could do for this website, please let me know.
